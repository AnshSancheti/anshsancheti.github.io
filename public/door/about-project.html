Endless Door

A hand-drawn interactive door that reveals another door every time it opens.

Canonical URL: https://anshsancheti.github.io/door/ Creator: Ansh Sancheti Status: Public interactive artifact

What it is

Endless Door is a minimal browser interaction built around an impossible object: opening the current door reveals the next door behind it, with no final room or destination.

Visitors can click, drag, or use the keyboard to open and close the door. The motion uses direct transforms with a deliberate acceleration and deceleration curve, no idle animation loop, and a reduced-motion mode. The page is designed as a self-contained visual object rather than a conventional application.
